# Spot governance questions before a campaign ships.

A browser-local issue-spotting checklist for cultural and AI-enabled campaigns, with official sources and clear limitations.

**Live:** https://aloha-governance-audit.vercel.app

## Repository contents

`next.config.js`, `package.json`, `pages`, `public`, `styles`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
